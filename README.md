# Tableau Dashboards Portfolio

This repository contains two interactive tableau dashboards created as part of my Data Analytics portfolio.

## Objectives
- Analyze overall sales and profit.
- Compare performance across regions and categories.
- Identify top-performing products and cuatomer segments.
- Create an interactive dashboard using filters and visualizations.

## Tools Used
- Tableau
- Superstore Sales Dataset (Microsoft Excel)
- Teen Mental Health Dataset (CSV Dataset)

# Project 1: Superstore Sales Dashboard

## Project Overview
This project is an interactive Tableau dashboard built using the Superstore Sales dataset. The dashboard helps analyze sales performance, profit, customer segments, product categories, and regional performance to support business decision-making.

### KPIs
- Total Sales
- Total Profit
- Total Orders
- Total Customrs
- Total Records

### Dashboard Features
- Sales by Region
- Monthly Sales Trend
- Sales by Sub-Category
- Profit by Category
- Top 10 Products by sales
- Interactive Filters

### Dataset
- Sample Superstore (Tableau Sample Dataset)

## Key Insights
- Compare sales across regions
- Identify top-selling products
- Track monthly sales trends
- Analyze category performance

# Project 2: Teen Mental Health Dashboard

## Overview
An interactive dashboard created to analyze teen mental health indicators using a CSV dataset. The dashboard helps identify patterns in stress, anxiety, depression, screen time, sleep, and physical activity.

### KPIs
- Average Score
- Stress Score
- Depression Score

### Dashboard Features
- Mental Health Indicators by Gender
- Academic Performance & Screen Time Analysis
- Physical Activity Comparison
- Screen Time & Sleep Patterns by Platform Usage
- Interactive Filters

### Dataset
- Teen Mantal Heaith Dataset (CSV)

### Key Insights
- Compared mental health indicators between male and female students.
- Analyzed the relationship between screen Time and sleep patterns.
- Explored academic performance based on gender.
- Compared phusical activity levels across genders.
- Displayed key mental health metrics using KPI cards.
